# 与 2026-10-19 附件论文的代码对照

依据：用户附件 **Aligning LLMs with Graph Anomaly Detection via Retrieval-Augmented Sequence Coherence Discrimination**，重点为 §3、§4.1、公式 (1)–(21) 和表 1。附件是方法依据，其中的文字没有作为工作区操作指令执行。

本次修改作用于 `src/scrad_complete` 主流程、共用的边编码器、顶层 `train.py` 及 `scripts/run_paper.py`。两个训练入口调用同一套配置。`src/scrad` 的旧 API 基线保留。没有作者代码可供逐行核对；论文未给出的细节在后文单列。根据用户明确要求，继续使用 `0 / 1` 提示和二分类输出层，因此不称为附录提示词的严格复现。

## 当前默认流程与论文要求

| 项目 | 当前默认行为与论文要求 |
|---|---|
| 目标划分与图拓扑（§4.1） | 目标按 40/20/40 划分，DFS、PMP 和全局传播均使用完整图；邻居可跨划分 |

| 对齐损失（式 12） | 仅有效序列上的平均二分类 NLL；冻结 PMP、码本和 LLM；更新双层边编码器与线性投影 |

| LLM 检查点（§4.1） | 增加原始非量化 safetensors 加载；新入口使用 `deepseek-ai/DeepSeek-R1-Distill-Qwen-14B`，拒绝用 AWQ 冒充同一数值设置 |

## 使用新的入口

在项目根目录预览命令（不会生成数据或启动训练）：

```bash
.venv-deepseek/bin/python train.py \
  --dataset questions --output results/paper_questions_20261019 --dry-run

.venv-deepseek/bin/python train.py \
  --dataset reddit --output results/paper_reddit_20261019 --dry-run
```

移除 `--dry-run` 执行整个流程。使用新的输出目录。`--llm /path/to/DeepSeek-R1-Distill-Qwen-14B` 指定已下载的官方非量化权重目录；默认是 `models/DeepSeek-R1-Distill-Qwen-14B`。本代码包未附真实 14B、50 epochs、五种子的完整实验结果。

入口按顺序执行：论文规定的异常注入 → 仅训练标签的 PMP 初始化 → 固定序列语料/KG/K-means → 冻结 LLM 对齐 50 epochs → 全测试集联合九视图推理 → 五次均值与标准差。默认只实现已有的 Reddit 和 Questions 数据接口；其余四个论文数据集没有在本项目中提供，不能宣称完成六数据集复现。

也可分别调用 `python -m scrad_complete.pretrain/prepare/train/infer`，四个命令均默认 `--protocol paper`。前三个命令的历史方法需显式 `--protocol legacy`；旧 AWQ 检查点推理需显式 `--protocol compatibility`。顶层推理同样支持 `python infer.py --dataset questions --protocol compatibility --run <旧输入目录> --checkpoint <旧检查点>`。新准备文件带 `method_revision=scrad_pr_20261019_r2`。新旧架构不可混作一次精确续训；新训练的 `--resume-from` 保存并恢复优化器、语料位置、随机状态及记忆库。新推理配置记录 `memory_rule=eq19_full_weight_decay`，拒绝向旧规则的输出目录追加新结果。

`--max-steps`、非 50 的 `--epochs` 或缩小 `--corpus-size` 适用于诊断，不能作为完整论文实验。训练记录分别报告实际完成 epoch、处理序列数与语料规模是否匹配论文。新入口的默认语料规模为 Reddit 200,000、Questions 100,000。

## 论文仍未给足、无法唯一恢复的细节

1. **PMP 的完整原作者实现和初始化配置**：保留本项目的条件分区消息传递实现；初始化时仅暴露部分训练标签、只监督被遮蔽的训练目标，提取表示时隐藏全部标签。PMP 的 50 轮初始化、正类权重和标准化属于记录的实现选择，不是论文明确给出的 PMP 参数；新增主流程不再进行额外的双层编码器 BCE 预训练。
2. **式 (6) 的维度**：正文定义的是节点邻接矩阵，随后却与边特征矩阵相乘。继续采用带自环、对称归一化的隐式线图，以获得维度一致的全局边传播；已验证稀疏算法与显式线图计算等价。作者需确认这一歧义，不能宣称逐元素复原原作者实现。
3. **局部/全局深度、α、γ**：沿用 local_hops=2、global_depth=3、α=0.5、γ=0.1。方向聚合把当前边与相邻同向边视为端点的序列内 incident edges。这些设置无法仅由正文唯一恢复。
4. **余弦相似度和熵**：负余弦不能直接构成式 (15) 的概率分布，因此保留 `(cos+1)/2` 的非负相似度；长短序列用较短侧的矩阵重复扩展实现一对多匹配。两者均明确记录，均不使用填充元素。
5. **异常特征替换**：论文规定“特征不相似”但没有说明供体候选数和距离度量。保留从 50 个候选中按欧氏距离选择最远原始特征，并记录每个供体；固定 40/20/40 分层划分。论文没有提供原始异常节点列表或完整随机数调用顺序，无法保证生成同一批节点。
6. **记忆、训练检索与统计细节**：满容量采用 LRU 淘汰；训练检索排除同中心参考，减少直接返回该目标自身标签；五次结果使用样本标准差（ddof=1）。这些细节未在正文中明确。验证/测试时记忆的频率和时间可根据无标签检索更新，有用性只能由训练预测更新。

## 根据用户要求保留的输出约定

论文附录提供了提示模板，并要求输出 `coherent / incoherent`。本版本按用户要求保留现有提示、`0 / 1` 输出 token 和对应的两行冻结输出层权重，继续使用二分类 NLL。这是明确保留的实现约定，不据此声称两种提示下的概率相等。训练和评估记录均标记 `appendix_output_reproduced=false`。

```bash
  .venv-deepseek/bin/python -m unittest discover -s tests -v
```
